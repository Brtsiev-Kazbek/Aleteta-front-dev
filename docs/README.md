## Справочник по коду

Собирается из комментариев в коде:

```bash
npm run docs:api
```

Результат — `docs/api/`, markdown с перекрёстными ссылками и переходами к
исходникам на GitHub. Пересобирайте после заметных правок публичных функций:
устаревший справочник хуже отсутствующего.

## Устройство в двух абзацах

Next.js на сервере, Supabase в качестве базы, хранилища и аутентификации.
Запись в базу идёт только через серверные действия (`app/actions/`) — клиент
не пишет напрямую никогда: `workspace_id` нельзя принимать от него, а
проверки, живущие в браузере, обходит любой прямой запрос. Правила доступа
описаны политиками в базе, а не условиями в коде.

Работа с моделью вынесена за границу приложения: серверное действие кладёт
задание в `ai_jobs` и возвращает управление, а считает Edge Function рядом с
базой. Причина простая — разбор договора идёт минутами, а запрос к серверу
живёт десять секунд.

## Что нужно знать до первого коммита

- **Схема меняется только миграциями.** Правка через веб-панель не попадёт в
  репозиторий и не воспроизведётся при переезде.
- **Перед коммитом:** `npm run typecheck && npm run lint && npm run build`.
- **Комментарии объясняют «почему».** «Что» видно из кода.
- **Приложение обязано открываться без базы** — на встроенном наборе данных.
  Это поддерживаемый режим, а не аварийный.
